✈️ Guía paso a paso

Monta COTIZALO en Telegram

Telegram sí funciona sin VPN en Cuba, a diferencia de Firebase (Google) y con incertidumbre sobre otros servicios en la nube. Aquí usamos un bot de Telegram como base de datos: toda la información vive como un archivo adjunto a un mensaje fijado en un grupo. Esta misma página tiene botones que llaman directo a la API de Telegram para hacer la parte técnica por ti.

⚠️ Aviso de seguridad honesto: el token de tu bot quedará visible en el código fuente de cotizalo.html — cualquiera que lo vea podría usar tu bot. Por eso: crea un bot y un grupo dedicados solo a esta app, sin nada más importante ahí. Si alguien abusa, puedes revocar el token al instante desde @BotFather con /revoke y repetir el paso 5.
1

Crear el bot

  1. Abre Telegram y busca @BotFather (el bot oficial verificado).
  2. Envíale el comando /newbot.
  3. Dale un nombre visible, ej. Cotizalo DB.
  4. Dale un usuario único terminado en "bot", ej. cotizalo_db_bot.
  5. @BotFather te va a responder con un token (algo como 123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx). Cópialo.
2

Crear el grupo y añadir el bot

  1. Crea un grupo nuevo en Telegram, ej. "Cotizalo Base de Datos".
  2. Añade tu bot (@cotizalo_db_bot o como lo hayas llamado) como miembro.
  3. Entra a los ajustes del grupo → Administradores → conviértelo en administrador.
  4. Asegúrate de que tenga permiso para fijar mensajes y eliminar mensajes (estos son los que usamos).
  5. Envía cualquier mensaje al grupo (ej. "hola") — lo necesitamos para el siguiente paso.
3

🔧 Herramienta: detectar el Chat ID

Pega tu token aquí abajo y presiona el botón. Va a leer los últimos mensajes que recibió tu bot (por eso escribiste "hola" en el paso anterior) y te va a mostrar el ID de tu grupo.

4

🔧 Herramienta: inicializar la base de datos

Con el token y el Chat ID, esta herramienta va a: enviar un archivo con una base de datos vacía a tu grupo, y fijarlo. Ese mensaje fijado será tu base de datos para siempre (se edita, nunca se reemplaza).

5

🔧 Generar tu archivo listo para usar

Nada de copiar y pegar código: este botón toma automáticamente el token, el Chat ID y el Message ID que ya generaste arriba, y te entrega un cotizalo.html descargable, ya configurado y listo para abrir.

6

Probarlo

  1. Abre el cotizalo.html que acabas de descargar (doble click), o súbelo a GitHub Pages.
  2. Debería aparecer "Conectando con Telegram..." un instante y luego cargar el catálogo.
  3. Prueba reportar un precio de cualquier producto — luego revisa tu grupo de Telegram: el archivo adjunto al mensaje fijado debería haberse actualizado (puedes verlo si descargas el archivo desde la app de Telegram).
  4. Si algo falla: abre la consola del navegador (F12 → pestaña "Console") y ahí verás el error exacto.
7

Configurar el administrador

  1. En la app, toca el ícono 🔑 en la esquina superior derecha.
  2. Como nadie ha creado un PIN todavía, te dejará crear uno — este PIN es compartido: cualquiera que lo conozca entra como administrador.
  3. Como administrador puedes exportar/importar toda la base de datos, eliminar reportes o compras conjuntas de cualquier persona, y cambiar el PIN.
💡 Guarda ese PIN en un lugar seguro — solo se puede recuperar creando uno nuevo desde el panel de administrador (necesitas ya estar dentro).
🎉

¡Listo! COTIZALO ya vive en Telegram

Ahora cualquier persona que abra tu HTML puede reportar precios, unirse a compras conjuntas y ver la tasa de cambio — todo guardado en un grupo de Telegram, sin depender de ninguna nube estadounidense.
